# Tysen Xylix Ω 使用教学

## 一、软件简介

Tysen Xylix Ω 是一款本地运行的图片转矢量图工具，支持两种输出：

- **彩色矢量图**：把照片/插画转成可编辑的 SVG，适合 Illustrator、AI 工具继续加工。
- **黑白线稿**：提取线稿并转成 SVG/PNG，适合临摹、上色、打印。

所有处理都在本机完成，图片数据不出电脑。

## 二、系统要求

- Windows 10 / 11（64 位）
- 建议 NVIDIA 显卡 + 最新显卡驱动（GPU 加速）
- **不需要安装 Python、CUDA 工具包或任何运行库**
- 无 NVIDIA 显卡也能运行，但会使用 CPU，速度较慢

## 三、安装方法

1. 把安装包所有文件放在**同一个文件夹**：
   - `TysenXylix-Setup.exe`
   - `TysenXylix-Setup-1.bin`
   - `TysenXylix-Setup-2.bin`
   - `TysenXylix-Setup-3.bin`
2. 双击 `TysenXylix-Setup.exe`，按提示下一步即可。
3. 首次启动若提示缺少某个模型，请到作者 GitHub 主页查看模型下载说明（安装包已内置大部分模型）。

## 四、界面总览

左侧导航：**转换** / **关于**

顶部 HUD：软件名、GPU 状态、GitHub 链接

下方日志终端：显示每一步进度和错误信息，卡住时先看这里。

## 五、彩色矢量图（默认模式）

1. 点击"选择图片"或直接把图片拖进窗口。
2. 设置参数：
   - **颜色数量**：数字越大颜色越丰富、文件越大；一般 16~64；自动档会按图片推荐。
   - **分层叠加模式**：大色块铺底、小色块叠加，推荐开启。
   - **大图快速分层**：大图卡顿时可勾选（会跳过微小色层，画质略降）。
   - **AI 超分 Real-ESRGAN**：低清图先放大再转矢量，可选 1x/2x/3x/4x。
3. 点击"开始转换"，完成后 SVG 自动保存到指定位置。

## 六、黑白线稿

1. 勾选"**线稿提取（白底黑线）**"。
2. 选择线稿风格（按推荐度排列）：
   - **Anyline**（推荐）：通用线稿，照片/厚涂/带文字都能用
   - **Anime2Sketch**：动漫专用，墨线干净
   - **自适应**：适合复杂图，可选手背景细节档位：
     - 背景细节·少 8/30·长100（默认）
     - 背景细节·多 5/20·长150
     - 背景细节·中 5/20·长100
     - 基础（无背景细节）
   - **AniLines detail / basic**、**MangaLine**：备用模型
   - dark、EdgeSketch、hybrid、Canny、ControlNet：应急备用
3. 密度选择：极简 / 标准 / 细节。
4. 转换完成会同时输出：`xxx.线稿.png`（位图线稿）和 `xxx.svg`（矢量线稿）。

## 七、参数区说明（按分类）

- **基本模式**：量化、不缩小原图、移底、一体化、模型分割、线稿开关、图片类型、自动识别
- **线稿**：风格、密度、自适应档位、少数派剪影
- **分层与增强**：分层叠加、快速分层、AI 超分
- **描摹**：描摹分辨率（不放大/2倍/3倍/4倍/5倍）
- **输出**：导出分组、保存位置

## 八、输出文件

- `.svg`：矢量图，可用 Illustrator / Inkscape / 浏览器打开
- `.线稿.png`：线稿位图，可直接打印或临摹

## 九、常见问题

**1. 卡在"分层描摹"很久**
大图 + 高色数 + 不缩放会非常慢。建议：勾选"大图快速分层"，或把描摹分辨率选低（2倍/3倍），或减少颜色数量。软件已内置自动超时提醒。

**2. 提示显存不足**
关闭其他占用显卡的程序（浏览器、游戏、直播软件），或降低颜色数量/分辨率，或勾选快速分层。

**3. 低清图效果差**
开启"AI 超分 Real-ESRGAN"，选 3x 或 4x，再转换。

**4. 日志显示"缺少模型"**
到作者 GitHub 仓库按说明下载对应模型文件放入 `models` 目录。

**5. 进程卡死**
关闭软件后重新打开；软件会在启动时自动清理上次残留的转换进程。
